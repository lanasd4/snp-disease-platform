# Logo Placement

Official logo path:

app/assets/logo.png

This logo is used in the Streamlit sidebar and Home page.

If the logo does not appear:
1. Make sure the file name is exactly logo.png
2. Make sure it is inside app/assets/
3. Restart Streamlit after replacing it

Approved visual identity:
- Navy/medical blue
- Teal
- Soft purple
- White cards
- Rounded dashboard layout
