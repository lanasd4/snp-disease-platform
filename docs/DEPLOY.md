# النشر على Streamlit Community Cloud

1. ارفع المستودع على GitHub (عام).
2. ادخل على https://share.streamlit.io وسجّل دخول بحساب GitHub.
3. **Create app** ← اختار المستودع والفرع `main`.
   - **Main file path:** `app/main.py`
   - **Advanced settings → Python version:** 3.13
4. بنفس صفحة الإعدادات، بخانة **Secrets** الصق (وغيّر القيم):

   ```toml
   SNP_ADMIN_USERNAME = "اسم-الادمن"
   SNP_ADMIN_PASSWORD = "كلمة-سر-طويلة-وعشوائية"
   SNP_ALLOW_REGISTRATION = "false"
   ```

5. **Deploy**. أول تشغيل بياخد كم دقيقة لينزّل المكتبات.

## ملاحظات

- حساب الادمن بينعمل تلقائياً أول مرة من الـ Secrets. كلمة السر لازم ما تبدأ بـ `CHANGE-ME`.
- قاعدة البيانات المنشورة ما فيها حسابات. أي حساب بينعمل على السيرفر ممكن ينمسح لما التطبيق يعيد التشغيل
  (الاستضافة المجانية ما بتحفظ الملفات)، فخلي التسجيل مسكّر بهالنسخة.
- صفحة شرح الذكاء الاصطناعي بتحتاج Ollama محلي، فعلى الاستضافة بتشتغل بالوضع الاحتياطي (بدون نموذج).
- أي تعديل بتعمله push على `main` بيتحدّث التطبيق تلقائياً.
